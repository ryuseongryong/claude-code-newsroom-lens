## 현재 repo 기본 컨텍스트 (자동 주입)

!`git ls-files | head -200`

!`git ls-files | wc -l`

## 분석 대상 입력값

$ARGUMENTS

## 대상 판별

`$ARGUMENTS` 값에 따라 하나만 고른다.

| `$ARGUMENTS` | 대상 | 확보 방법 |
|---|---|---|
| 비어 있음 | 현재 repo | 위에 주입된 파일 목록을 출발점으로 쓴다 |
| 로컬 경로 | 그 경로 | 주입된 목록은 무시하고 해당 경로에서 다시 탐색한다 |
| repo URL | 원격 저장소 | `git clone --depth 1 <URL> /tmp/arch-viewer/<repo-name>` 로 얕게 복제한 뒤 그 경로를 분석한다 |

경로가 존재하지 않거나 복제가 실패하면 문서를 만들지 말고 실패한 대상과 사유 한 줄만 출력하고 끝낸다.
주입된 목록이 200개에서 잘려 있으면(파일 수가 200보다 큼) 전체 목록을 다시 확보해 판단한다.

## 분석 절차

1. **골격 파악** — 매니페스트(`package.json`, `pyproject.toml`, `go.mod`, `Cargo.toml`, `pom.xml` 등), 빌드·배포 설정, IaC, CI 워크플로를 먼저 읽는다. 여기서 언어·런타임·프레임워크·배포 형태를 확정한다.
2. **진입점 추적** — `main`/`index`/`app`/`cmd`/핸들러/라우터/`bin` 스크립트에서 시작해 호출 방향을 따라간다. 디렉터리 이름으로 역할을 짐작하지 말고, 실제 import·require·라우트 등록을 근거로 삼는다.
3. **경계 식별** — 계층(진입점 / 도메인 로직 / 저장소 / 외부 연동)과 모듈 간 의존 방향을 정리한다. 순환 의존, 계층을 건너뛰는 호출은 따로 표시한다.
4. **외부 의존 수집** — DB, 큐, 캐시, 외부 API, 인증 공급자, 환경변수·시크릿 키 이름을 모은다. 시크릿 **값**은 절대 문서에 옮기지 않고 키 이름만 적는다.
5. **핵심 흐름 선정** — 이 저장소를 설명하는 대표 요청·작업 흐름 1~2개를 고른다. 진입 → 처리 → 저장/응답까지 실제 경로로 잇는다.
6. **근거 확인** — 문서에 적는 모든 경로·모듈명·함수명은 실제 존재하는 것만 쓴다. 코드를 실행하거나 테스트를 돌리지 않는다. 읽어서 확정하지 못한 부분은 지어내지 말고 `## 확인 필요` 로 넘긴다.

## 문서 작성

**저장 위치** — 현재 repo 대상이면 `docs/architecture.md`, 외부 대상이면 현재 작업 디렉터리의 `docs/architecture-<대상-repo-이름>.md` 에 쓴다. 외부 저장소에는 절대 쓰지 않는다. 같은 이름의 파일이 이미 있으면 먼저 읽어 보고, 덮어쓸지 새 파일로 쓸지 판단한 뒤 진행한다.

**글자 예산** — 문서 전체를 공백 포함 5,000자 이내로 맞춘다. 예산의 상당 부분을 도면이 쓰므로 산문은 압축해서 쓴다: 각 설명은 1~2문장, 표 칸은 명사구, 같은 사실을 산문과 표에 두 번 적지 않는다. 코드 원문 인용·파일 전체 나열·튜토리얼식 설명은 넣지 않는다. 작성 후 `wc -m` 으로 실제 글자 수를 확인하고, 초과하면 도면을 줄이는 대신 산문을 더 압축한다.

## 출력 형식

아래 6개 섹션을 이 순서대로 모두 채운다. 3번과 4번 도면은 필수 슬롯이며 비우거나 산문으로 대체할 수 없다. 도면은 GitHub에서 렌더되는 mermaid 로 쓰고, 노드 라벨에는 실제 모듈·디렉터리 이름을 넣는다.

~~~
# <대상 이름> 아키텍처

## 1. 개요
- 한 줄 요약: <이 저장소가 하는 일>
- 스택: <언어 / 런타임 / 주요 프레임워크>
- 진입점: <실행이 시작되는 파일 또는 명령>

## 2. 구성 요소
| 경로 | 역할 | 의존 대상 |
|---|---|---|
| <경로> | <역할> | <의존> |

## 3. 구조 도면
```mermaid
graph TD
  <계층·모듈 노드와 의존 방향>
```

## 4. 핵심 흐름
```mermaid
sequenceDiagram
  <진입에서 응답까지의 대표 흐름>
```

## 5. 데이터와 외부 의존
- <저장소·외부 서비스·환경변수 키>

## 6. 확인 필요
- <읽어서 확정하지 못한 지점 또는 없음>
~~~

마무리로 저장 경로와 확인한 글자 수 한 줄만 보고한다.
